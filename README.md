# ice-cream v0.6.4

ice-cream 是一款面向 Zotero 的论文阅读助手。它可以把当前论文或多篇论文交给大模型，结合全文、原始 PDF、页面图像与连续对话，帮助你解释公式、读取图表、比较论文和整理笔记。

## 核心功能

- **论文全文问答**：读取 Zotero 条目元数据、摘要和 PDF 全文，并根据问题定位相关页面。
- **PDF 与视觉理解**：支持向模型发送原始 PDF；当模型或接口不接受 PDF 时，可自动改用相关页面图像。
- **多论文工作区**：`Use Selection` 可以累积多次选择的论文，自动去重，适合对比方法、实验和结论。
- **连续对话记忆**：每轮都会携带当前对话的文本历史，并从已加入的论文中重新检索与新问题相关的内容。
- **精确内容定位**：结合编号匹配、标题与图注识别、相邻页扩展和相关性重排，定位表格、图片、公式及章节。
- **清晰的引用标记**：回答可使用 `[S1:p2]`、`[S2:A2:p5]` 等标签标明论文、附件和页码。
- **Markdown 与公式排版**：支持结构化 Markdown、代码块、表格以及 KaTeX 数学公式显示。
- **本地会话管理**：自动保存文本对话，可切换历史会话、继续提问或彻底删除指定条目。
- **Zotero 笔记保存**：`Save Note` 可将当前对话保存为所选论文下的子笔记。
- **灵活窗口**：窗口可移动、缩放，并可用右上角别针设置为始终置顶。

## 独特能力

### 一次加入，后续继续追问

点击 `Use Selection` 后，论文会加入当前会话。首个已启用论文上下文的提问可以发送全文和视觉材料；后续提问不会机械地重复上传整份 PDF，而是保留对话历史，并从本地论文全文中检索与新问题最相关的页面。这兼顾了信息完整性、连续追问和传输效率。

### 原始 PDF 与页面图像自动切换

对于支持原始 PDF 的模型，插件优先直接发送 PDF。若当前模型或 API 端点拒绝 PDF，插件会渲染并发送相关页面图像后重试，因此图、表、公式和页面布局仍可参与回答。

### 面向图表公式的页面检索

当你询问“表 3”“图 9”“公式 (38)”或某个章节时，插件会优先识别精确编号、标题和图注，并扩展相邻页面，再按相关性整理证据，减少只命中文本片段却遗漏完整图表的情况。

## 安装方法

1. 下载上方的 `.xpi` 文件。
2. 打开 Zotero，进入 **工具 → 插件**。
3. 点击插件管理器右上角的齿轮按钮。
4. 选择 **Install Add-on From File / 从文件安装插件**。
5. 选择下载的 `ice-cream-0.6.4.xpi`，确认安装并重启 Zotero。

安装完成后，Zotero 主窗口右下角会显示 **ice-cream** 入口。

## 首次配置

打开 ice-cream，展开 **Settings**：

1. 在 **Provider** 中选择模型提供方。
2. 在 **API key** 中填写对应提供方的密钥。
3. 在 **Model** 下拉菜单中选择模型；也可以填写兼容端点提供的模型名称。
4. 使用自定义或兼容接口时，检查 **Endpoint** 是否与服务商文档一致。
5. 按需要设置 **Context characters**，它表示一次请求可携带的论文提取文本字符预算。
6. 选择新对话是否包含元数据、全文和 PDF。

插件已适配 OpenAI、Claude、DeepSeek、Qwen 和 OpenAI 兼容接口。模型名称与接口能力可能由服务商更新，配置时请以你的 API 账户和服务商文档为准。

## 基本使用

1. 在 Zotero 中选中一篇论文，或在阅读器中打开论文。
2. 点击右下角 **ice-cream** 打开助手窗口。
3. 点击 **Use Selection**，把当前论文加入会话。
4. 输入问题并发送，例如“总结本文的方法”“解释公式 (12)”或“读取图 4 并说明结论”。
5. 继续追问时直接输入新问题；无需再次点击 `Use Selection`，除非要加入新论文或重新附带论文材料。

发送过程中会显示当前模型、处理状态和思考时间。回复完成后会显示总用时。你可以终止当前请求，也可以修改已有问题后重新发送。

## 多论文对比

在 Zotero 中选择多篇论文后点击 `Use Selection`，或依次查看不同论文并多次点击 `Use Selection`。插件会把来源累积到当前工作区并自动去重，最多可保留 12 个来源。

状态栏中的 `Pinned research workspace` 会显示当前已加入的来源数量。随后可以直接提问：

- “比较这些论文的系统模型和关键假设。”
- “整理每篇论文使用的数据集、评价指标和主要结果。”
- “这些方法在哪些条件下结论不一致？”

点击 `Clear` 会结束当前会话并从本地删除它的对话记录，同时建立一个新的空白会话。

## PDF 与全文选项

- **Metadata**：发送标题、作者、日期、DOI、摘要等条目信息。
- **Full text**：发送提取后的论文全文，并用于后续的本地相关页面检索。
- **PDF**：在当前已启用 `Use Selection` 的提问中附带原始 PDF 或兼容的页面图像。
- **Context characters**：控制请求中提取文本的最大字符预算；数值越大，覆盖内容通常越多，同时也会使用更多模型上下文。

单次请求最多附带 8 个原始 PDF，每个文件不超过 64 MB，合计不超过 120 MB。超出时，插件仍会尽量使用提取文本和相关页面图像提供证据。

## 历史会话

- 对话开始后会自动保存文本记录，并根据对话主题生成名称。
- 使用窗口顶部的会话下拉菜单可以切换到旧会话并继续提问。
- 每个历史条目右侧的圆圈叉号按钮会永久删除该条目。
- `Clear` 会删除当前会话的本地文本历史并开始新会话。
- 为避免占用空间，历史记录不会保存 PDF 文件或论文全文副本；再次打开旧会话时，插件会通过记录的 Zotero 条目重新读取论文内容。

## Save Note

点击 **Save Note** 后，插件会把当前对话保存为 Zotero 笔记：

- 已选中普通文献条目时，保存为该文献下的子笔记。
- 当前选中的是 PDF 附件时，优先保存到它的父文献条目下。
- 没有可用父条目时，保存为独立笔记。

可以在 Zotero 右侧的 **笔记** 区域或条目的子项目列表中找到保存结果。

## 公式与表格

插件会要求模型使用规范的 Markdown/LaTeX 公式格式，并在窗口中使用 KaTeX 渲染。行内公式使用 `$...$`，独立公式使用 `$$...$$`。表格会按 Markdown 结构排版，较宽内容可以横向查看。

如果原 PDF 中的公式是扫描图像、字体编码异常或页面非常复杂，可以在提问中明确指出公式、图表编号和页码，插件会优先检索并附带相邻页面视觉证据。

## 本地数据与隐私

- 对话文本保存在本机 Zotero 数据目录中。
- PDF 文件和提取全文不会复制进历史会话文件。
- API 密钥保存在 Zotero 的本地偏好设置中，不会写入 GitHub 仓库。
- 论文内容与问题会按你的操作发送到所配置的模型 API；请根据论文保密要求和服务商隐私政策决定是否上传。

## 自动更新

插件包含 Zotero 更新地址。发布新版本后，Zotero 可以通过 `updates.json` 检查兼容更新。你也可以随时从本页下载最新版 XPI 覆盖安装。
